# 金币价格趋势查询页设计

## 目标

在仓库根目录新增 `frontend` 前端应用，提供一个无菜单的单页数据看板。用户可选择精确到自然日的起止日期并查询该区间内的金币价格，用折线图查看价格走势。

首版使用本地样例数据；页面的数据访问边界应独立封装，以便后续用后端接口替换，不改动页面组件和图表配置。

## 范围

包含：

- 单页「金币价格走势」看板，无侧栏、顶部导航或多页面路由。
- 包含年、月、日的起始与结束日期条件，以及「查询价格」按钮。
- 以日为横轴、价格（元／金）为纵轴的折线图；纵轴刻度固定在图表左侧。
- 根据当前查询结果显示最新价格、区间最高价及区间最低价。
- 空数据、加载中和查询失败的页面内状态。
- 可替换的样例数据源与明确的后端 API 契约。

不包含：

- 用户账户、权限、菜单、历史收藏、导出或价格预警。
- 后端 API、数据库查询、爬虫逻辑或部署配置。
- 对同一天多个 `rank` 记录的业务聚合规则；首版前端假定接口已返回一个日价格。

## 视觉与布局

页面为居中、最大宽度约 1180 px 的浅暖灰背景数据页，使用暖白内容卡、低饱和金棕色趋势线及细分隔线。标题区仅包含「DD373 MARKET DATA」小标与「金币价格走势」标题，不出现任何导航元素。

主卡片从上至下由以下区块组成：

1. 查询栏：左起依次为「查询区间」标签、开始日期、连接词「至」、结束日期；「查询价格」按钮固定在右侧。窄屏下日期字段换行，按钮独占一行。
2. 摘要栏：最新价格、区间最高价、区间最低价三列；最新价格附带与前一日比较的涨跌幅。窄屏下改为纵向排列。
3. 图表栏：标题「价格趋势」与图例在同一行。纵轴价格刻度在左侧，横轴显示若干日期标签；趋势线的面积使用淡金色渐变。图表提示框应显示该点的日期与价格。
4. 数据说明：提示价格单位为「元／金」，按自然日展示；缺少某日数据时不伪造或插补价格。

## 用户交互与校验

- 初始值使用样例数据覆盖的完整日期范围。
- 用户点击「查询价格」后，以闭区间筛选数据，即同时包含开始日和结束日。
- 开始日期晚于结束日期时，不发起数据读取，在结束日期附近显示「结束日期不能早于开始日期」。
- 日期为空时，显示对应的必填提示。
- 查询区间内没有数据时，保留已选日期与查询栏，摘要和图表区域展示空状态「该时间范围暂无价格数据」。
- 数据源读取失败时，保留已选日期与查询栏，展示可重试的错误状态；不显示过期图表或摘要。
- 加载时，查询按钮禁用并显示加载提示，摘要和图表显示骨架占位。

## 数据模型与接口边界

前端内部使用如下日价格模型：

```ts
type DailyGoldPrice = {
  date: string;       // YYYY-MM-DD，Asia/Shanghai 自然日
  price: number;      // 元／金，例如 0.0124
};
```

页面只能依赖一个 `getDailyGoldPrices(startDate, endDate)` 数据访问函数。首版由该函数过滤本地样例数据；接入后端时保持函数签名不变，并改为请求：

```text
GET /api/gold-prices/daily?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD
```

成功响应为按 `date` 升序排列的 `DailyGoldPrice[]`。后端应以 `Asia/Shanghai` 将采集时间归属到自然日，并在后端完成同日多条爬虫记录的聚合。页面不自行将 `fetched_at` 转换为日期，也不自行挑选 `rank`。

`price` 使用 JSON 数字传输，页面显示时固定为 4 位小数；当前产品数据精度来自数据库的 `numeric(12, 8)`，后端不得在聚合前转换为二进制浮点值。

## 组件边界

- `GoldPricePage`：管理日期筛选状态、请求状态与页面布局。
- `DateRangeFilter`：渲染两个原生日期输入框、执行前端校验并提交区间。
- `PriceSummary`：仅根据已成功加载的日价格计算与展示 3 项摘要。
- `PriceTrendChart`：仅接收有序日价格数组；负责左侧纵轴、横轴和 tooltip，不读取数据或解析日期输入。
- `goldPriceRepository`：封装本地样例数据及未来 API 调用的唯一替换点。

## 验收标准

- 首次打开页面即可看到样例数据的趋势线、左侧纵轴和 3 项摘要。
- 两个日期输入均精确到日，合法查询仅显示闭区间内的数据点。
- 图表的纵轴刻度始终位于左侧；横轴为日期，价格单位清晰可见。
- 日期倒置、空输入、加载、空数据和请求失败均有独立且可理解的状态。
- 在桌面与窄屏宽度下，查询条件、摘要及图表均不溢出或遮挡。
- 仅替换 `goldPriceRepository` 的数据实现即可接入约定接口，页面和图表组件无需改动。

## 测试重点

- 日期校验及闭区间过滤。
- 摘要值：最新、最高、最低及相邻日涨跌计算。
- 数据为空、读取失败与加载中状态。
- 图表接收的日期顺序、左侧纵轴渲染和 tooltip 格式。
- 至少 1 个窄屏视口的布局回归测试。
